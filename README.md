# CampusConnect Dev

## Developer Onboarding Assistant

CampusConnect Dev is a developer onboarding assistant designed to help beginners understand unfamiliar software projects quickly and confidently.

## Problem

When developers join an unfamiliar project, they often spend significant time trying to understand the project structure, setup process, important files, beginner tasks, and potential issues.

## Solution

CampusConnect Dev organizes this onboarding process into an easy-to-use interface.

It provides:

- Project analysis
- Project structure explanations
- Step-by-step setup guide
- Beginner-friendly task checklist
- Project health check
- Issue and code quality checker
- Progress tracking

## Features

### Analyze Project
Provides an organized onboarding report containing project information, important files, setup steps, beginner tasks, and areas to investigate.

### Project Structure Explorer
Explains common folders and files in a beginner-friendly way.

### Setup Guide
Provides a step-by-step setup checklist with progress tracking.

### Project Health Check
Reviews areas such as documentation, configuration, security, code quality, and deployment readiness.

### Issue & Code Quality Checker
Provides a mock scan of code quality, bugs, security, documentation, and maintainability.

## Technology

- HTML
- CSS
- JavaScript
- IBM Bob 2.0

## Purpose

The project aims to reduce the manual effort and confusion involved in developer onboarding by organizing important project information into one beginner-friendly workflow.
